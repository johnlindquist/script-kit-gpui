What is the difference between a Rust trait object and an impl Trait return?
A trait object (dyn Trait) erases the concrete type and dispatches dynamically through a vtable, so one value can hold any implementor at runtime. impl Trait in return position keeps a single concrete type, resolved statically at compile time — no vtable, no allocation, but every return path must produce the same type.
